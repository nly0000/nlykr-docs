# nly.kr 문서

이 저장소는 **nly.kr** 서비스의 공식 문서와 주요 기능에 대한 개요를 제공합니다.

nly.kr는 URL 단축, QR 코드 생성, 링크 관리 및 온라인 문서 도구를 제공하는 웹 기반 서비스입니다.

## 공식 링크

- [nly.kr 공식 웹사이트](https://nly.kr/)
- [nly.kr 무료 URL 단축기](https://nly.kr/create-short-url)
- [URL 단축 API 문서](https://nly.kr/api)
- [Chrome 확장프로그램](https://nly.kr/chrome-extension)

---

## 개요

nly.kr는 링크 공유와 문서 배포를 간편하게 만들기 위한 웹 서비스를 제공합니다.

기본적인 URL 단축 기능은 별도의 회원가입 없이 사용할 수 있으며,  
회원가입 후에는 링크 관리와 클릭 통계 등의 추가 기능을 이용할 수 있습니다.

---

## URL 단축 서비스

[nly.kr URL 단축기](https://nly.kr/create-short-url)는 긴 주소를 짧고 공유하기 쉬운 링크로 변환할 수 있는 서비스입니다.

### 주요 특징

- 로그인 없이 즉시 URL 단축 가능
- 짧고 단순한 URL 구조
- HTTPS 기반 안전한 리다이렉션
- QR 코드 자동 생성
- 사용자 지정 주소 지원
- 회원 대상 클릭 및 접근 통계 제공
- 개발자용 API 제공

### 활용 사례

- 카카오톡, 문자, 메신저 및 SNS 링크 공유
- 오프라인 인쇄물용 QR 코드 생성
- 긴 캠페인 및 추적 URL 공유
- 문서, 프레젠테이션 및 웹사이트에서 깔끔한 링크 사용

URL 단축 기능 바로 사용하기:  
https://nly.kr/create-short-url

## URL 단축 API

개발자는 nly.kr의 URL 단축 기능을 웹사이트, 애플리케이션 및 자동화 서비스에 연동할 수 있습니다.

API 사용 방법과 엔드포인트는 공식 문서에서 확인할 수 있습니다.

[URL 단축 API 문서 보기](https://nly.kr/api)

## Chrome 확장프로그램

nly.kr는 웹페이지를 탐색하면서 현재 페이지 또는 특정 링크를 바로 단축할 수 있는 Chrome 확장프로그램을 제공합니다.

웹사이트로 다시 이동하지 않고 브라우저에서 빠르게 단축 링크를 생성할 수 있습니다.

[nly.kr Chrome 확장프로그램 자세히 보기](https://nly.kr/chrome-extension)

---

## PDF 문서 생성 서비스

nly.kr는 웹에서 문서를 작성하고 PDF로 생성할 수 있는 기능을 제공합니다.

견적서, 이력서, 회의록, 증명서 등의 문서를 작성한 후  
PDF 파일로 다운로드하거나 링크 형태로 공유할 수 있습니다.

### 주요 기능

- 웹 기반 문서 작성
- PDF 파일 생성 및 링크 공유
- 비공개 문서 및 비밀번호 보호
- 문서 조회 통계 제공
- 업무 및 행정 문서 활용

[PDF 서비스 자세히 보기](https://nly.kr/pdf-product-new)
